# <group> <case-count> <kind> <share>
#
# kind is a graded property, not a label: the scorer reads it.
#   gate    proof of life + inherited regression. Binary as a SET: if any
#           gate group fails the step scores 0 however good the new work
#           is. Earns nothing of its own. Share column is '-'.
#   scored  this step's new capability. Shares are integers and the scorer
#           normalises them, so the weights sum to exactly 1.0.
#
# reward = gate x score. A no-op preserves inherited behaviour (gate=1) and
# implements nothing new (score=0), so it scores exactly 0.
#
