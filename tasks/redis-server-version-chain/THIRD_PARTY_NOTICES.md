# Third-party notices — redis-server-version-chain

A Java Redis-compatible server built across the Redis release train, 2.8 to
8.0, graded with Redis's own Tcl test suite and with RDB/AOF fixtures produced
by real `redis-server` binaries.

The BSD-3-Clause `COPYING` copyright line differs by release: `2006-2015` for
2.8.24 through 5.0.14, and `2006-2020` for 6.0.20 through 7.2.x. The text in
`LICENSES/BSD-3-Clause.txt` is the 7.2.7 `COPYING`, i.e. the `2006-2020` line.

The Redis 7.4 and 8.x `LICENSE.txt` files are combined documents. The three
license files above reproduce their three sections verbatim, including the
section headings; the combined file's preamble reads:

## Modifications made by the benchmark

- Upstream test-suite files under `steps/*/tests/suites/` are copied unchanged.
- RDB and AOF fixtures are generated by running the corresponding real
  `redis-server` release; they contain data, not upstream source.
- The documentation under `environment/docs/redis/` is a subset of `redis/docs`
  (`content/commands`, `content/develop/data-types`,
  `content/develop/reference` without `modules/`, plus `LICENSE`) copied
  unchanged; `environment/docs-provenance.txt` records the source commit,
  SHA-256 and conversion steps.
- The Lua 5.1 manual and LuaJ javadoc are documentation subsets; no Lua or LuaJ
  source is shipped.
- No Redis source code is bundled. The task's Java implementation, tests other
  than the copied suites, and instructions are authored content.
