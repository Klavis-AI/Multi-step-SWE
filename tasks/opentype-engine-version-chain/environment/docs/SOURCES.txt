# Documents shipped to the offline agent under /opt/docs.
# Format: <sha256>  <kind>  <path under /opt/docs>  <official source URL>
#   kind "file": the download as published; sha256 of the file.
#   kind "md":   a learn.microsoft.com page in its published Markdown rendition
#                (the page's own "Copy Markdown" link, ?accept=text/markdown).
#                The site-metadata front matter (the leading block between two
#                `---` lines) is dropped; sha256 of what remains, which is the
#                shipped file.
#                The site has no versioned URL: if Microsoft republishes a page
#                the check fails and names it; re-pin from the same URL.
# Fetched and checked (curl + sha256sum -c) by the `docs` stage of
# environment/Dockerfile. /data/spec carries most OpenType 1.9.1 chapters; these
# are the ones it does not carry that the steps rely on, plus the documents the
# shipped chapters and INTERFACE.md defer to:
#  - opentype/ttch01, tt_instructions: TrueType fundamentals and the TrueType
#    instruction set (the grid-fitting chapters in /data/spec build on them)
#  - opentype/kern, vhea, vmtx, vorg, base, hdmx, ltsh, vdmx, ebdt, eblc: tables
#    the corpora carry (cblc/cbdt defer to EBLC/EBDT for their shared formats)
#  - opentype/scripttags, languagetags, featuretags, features_*: the OpenType
#    Layout tag registry (script, language-system and feature tags)
#  - harfbuzz/utilities.html: the HarfBuzz manual's utilities chapter that
#    INTERFACE.md cites (https://harfbuzz.github.io/utilities.html), pinned to
#    the harfbuzz.github.io commit whose source equals HarfBuzz 14.4.0's
#    docs/usermanual-utilities.xml
#  - unicode/core-spec-17.0.0-chapter-3.html: The Unicode Standard 17.0.0,
#    chapter 3 (normalization: 3.11; conjoining jamo / Hangul syllables: 3.12)
#  - w3c/compositing-1-20240321.html: Compositing and Blending Level 1, which
#    the COLR chapter defers to for the PaintComposite modes
#  - freetype/fterrdef.h, fterrors.h: FreeType 2.14.3's error-code table and
#    the header that expands it. /data/spec/ftlint.c builds the text of its
#    `error = 0x...., <message>` lines from them; a table of codes and
#    messages, no code
