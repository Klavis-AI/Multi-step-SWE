Step-09-only fixtures.

dsa-1024-sha256.pem      A self-signed 1024-bit DSA certificate whose signature
                         algorithm is dsa-with-sha256, copied verbatim from the
                         upstream certificate-transparency-go v1.1.2 x509 test
                         corpus (const dsaCert1024WithSha256).
dsa-1024-sha256.msg      The exact message body that was signed.
dsa-1024-sha256.sig.hex  The DER ECDSA-style (r,s) DSA signature over that
                         message, hex, from the same upstream test.

Both the certificate's own self-signature and the detached signature above need
the FIPS 186-3 section 4.6 rule that a hash longer than the subgroup order is
truncated before verification. The step-08 fork does not apply that rule, so it
rejects both.
