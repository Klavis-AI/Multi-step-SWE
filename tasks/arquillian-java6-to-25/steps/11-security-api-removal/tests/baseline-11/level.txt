# 66 is Java 22. 65 is what step 10 reached and what this rung must not fall
# below on the way.
#
# 66 AND NOT 65. The level move here is not a rung of the ladder chosen for
# its own sake: `_` as a catch-parameter name is a KEYWORD from release 22
# (JEP 456), so the language work this rung asks for cannot be written below
# it. A tree that renamed all 28 parameters and left the release at 21 does
# not compile; a tree that moved the release and renamed nothing gains nothing,
# because C-1 is x0.04 of this step's mean and C-3 is the rest of it.
#
# TWO GATES READ THIS FILE AND THEY READ DIFFERENT KEYS. C-1 reads `major=` and
# scores the fraction of the tree that reached 66. B-4 reads `was=` and asks for
# ONE major across everything the build compiled, not below 65. Neither number
# is a literal in test.sh.
major=66
# What the jars carried on the way in, so a report can say what moved.
