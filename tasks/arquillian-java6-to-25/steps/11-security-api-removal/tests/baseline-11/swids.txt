# and behavior.missing[] report and this list is compared against those.
#
# THREE CARRY THE NULL ANSWER. JEP 441: a pattern switch on a reference throws
# NullPointerException unless a `case null` label is present, where the
# if-chain it replaces falls through every arm. This tree answers that input
# three different ways -- a quiet return in BeansXMLProtocolProcessor#process,
# an NPE already in ResourceInjectionEnricher#resolveResource, and unreachable
# in both ServletProtocolDeploymentPackager chains, where TestDeployment's
# constructor throws IllegalArgumentException before either dispatch is entered
# -- so there is no static rule that is right at all four sites, and NOTES 15.4
# made it a must-flip input instead. The packagers' answer being the unreachable
# one is why they need no `case null`, and why no recording of a null can
# score them.
#
# TWO CARRY THE UNMATCHED-TYPE FALL-THROUGH, which is what the packagers CAN be
# scored on. Three arms each, six of this leg's ten: a ResourceAdapterArchive
# matches no arm of either, and both methods raise an IllegalArgumentException
# whose text names the packager and the archive's own implementation class.
# That is the `default` the conversion has to keep.
#
# C-3's structural halves are multiplied by the fraction of these that still

# the chain returned, or handle an archive where it threw, scores 0 on C-3, and
