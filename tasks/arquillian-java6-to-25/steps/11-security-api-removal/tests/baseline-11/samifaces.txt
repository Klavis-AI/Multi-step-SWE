# Step 04 -- the 24 single-abstract-method interfaces the tree declares, and
# C-2's whole denominator.
#
# `path Name` pairs, and the pair is the key because 65 interfaces are declared
# across the tree and `Operation` alone is the name of four of them. Verified
# unique: 65 records, 65 distinct (path, Name) at both the baseline and the
# golden, over the identical 65-interface population.
#
# WHY THIS SET IS THE TREE'S AND NOT THE GOLDEN'S
# -----------------------------------------------
# The list was copied out of the GOLDEN's interfacedecl[...] records --
#
#   sed -n 's/^interfacedecl\[[0-9]*\]=//p' <golden report> \
#     | awk '$0 ~ /annotated=yes/ {split($1,a,":"); print a[1] " " $2}' | sort -u
#
# -- which would be scoring the solution's choices if the choice were free. It
# is not, and three measurements close it:
#
#   1  @FunctionalInterface is compiler-enforced. The golden's report carries
#      source.ok=yes, so javac accepted all 24 annotations, so all 24 are SAMs.
#      Not one of them is here because the solution said so.
#   2  iface.sam=24 at the baseline AND at the golden. So the tree declares
#      exactly 24 SAMs, the annotated set holds 24 distinct ones, and 24
#      distinct members of a population of 24 is the population.
#   3  An independent counter agrees. `abstract=1` in the BASELINE report --
#      a different field, measured on the input tree before any annotation
#      existed -- selects exactly these 24 pairs, with no difference in either
#      direction. `abstract=1` is NOT the SAM rule (gates/selftest pins the
#      three shapes where it disagrees: a SAM that redeclares equals(Object)
#      reads 2, a SAM that declares nothing and inherits its method reads 0,
#      and a non-SAM that declares one and widens reads 1) -- which is what
#      makes the agreement worth having. It coincides on THIS tree, so a
#      mis-transcribed line here would have to fool both readings.
#
# So the migration has one correct answer for this gate and the candidate is
# scored against the tree's own census.
