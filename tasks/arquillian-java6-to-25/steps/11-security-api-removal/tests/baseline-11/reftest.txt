#
# BOTH HALVES ARE SCORED AND THE HOLD HALF IS NOT AN OMISSION. A type pattern
# needs two things the source must already contain: a value to bind and a type
# to NAME at compile time. `c.isInstance(v)` and `c.isAssignableFrom(..)`
# have a Class VALUE where the type must go, and `X.class.isAssignableFrom(y)`
# has a Class object where the value must go. There is no `instanceof` that
# takes either. A candidate who "converts" one of those 14 has written code
# that does not compile or does not mean the same thing.
#
# WHAT THE CONV HALF IS SCORED ON IS A PRESENCE AND NOT AN ABSENCE. The gate
# asks that the reflective form be gone from the method AND that the type it
# named be named by a language type test in the same method -- an `ipattern`
# record or a `swpat` arm. Step 09's C-2 graded `kind=bound`, which a
# deletion also satisfies, and needed a third total-site term to shut that door.
# Here the door is shut by the leg's own conv term: delete the code and the
# type is named by nothing.
#
# WHICH LANGUAGE FORM IS NOT ASKED. Ten of the 13 sit in the four chains of
# chain.txt and a pattern switch is the natural home for them, but a candidate
# who writes an `instanceof` chain instead still satisfies C-2 here -- and
# does not satisfy C-3. Two legs, two questions, and neither of them is taste.
