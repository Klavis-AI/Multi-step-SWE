# The step-02 test toolchain, warmed separately from warm/deps.txt.
#
# Separately, and not by appending to that file, because Gradle resolves one
# configuration with newest-wins: junit:junit:4.13.2 and junit:junit:4.8.1 in
# the same configuration select 4.13.2 and 4.8.1's jar is never fetched, so the
# arquillian-testng module -- which still compiles its own suite against the
# 2011 junit -- would resolve over the network at grading time. Two projects,
# two resolutions, both versions cached. It also keeps warm/ byte-identical in
# every step's build context, which is what lets steps share that layer.
#
# Versions are the ceilings JDK 8 allows, and the instruction names them:
# Jupiter 6.x requires Java 17 and Mockito 5.x requires Java 11.
