# The class-file major version this rung targets.
#
# Staged rather than written into the verifier, for one reason: B-4 and the
# step's instruction have to be talking about the same number, and on a
# thirteen-rung ladder the number changes at six of the rungs. A literal in
# test.sh is a literal that gets copied forward and not edited -- which is the
# failure that reads as a pass, because a tree compiled to 52 against a gate
# still asking for 51 fails a gate the candidate did satisfy, and a tree left
# at 51 against a gate asking for 51 passes one it did not.
#
# 52 is Java 8. The ladder: 50 = Java 6 (steps 01-02), 51 = Java 7 (03),
# 52 = 8 (04-05), 54 = 10, 55 = 11, 61 = 17, 65 = 21, 69 = 25.
#
# Steps 01-05 all grade on eclipse-temurin:8-jdk and express the rung through
# Gradle's sourceCompatibility/targetCompatibility, so this number moves from
# 51 to 52 at THIS rung and stays there through step 05; see NOTES 8.3.
#
# The scorer validates this on read and refuses to grade if it is missing or
# implausible, so that a staging mistake cannot become a zero that looks like a
# measurement about the tree.
major=52
