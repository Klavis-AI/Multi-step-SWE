# the 935 recordings log an outgoing request, and all 15 are on this list; the

# non-HTTP address, an unreachable port, a null executor). No recording outside

# non-HTTP address, the redirect that must still be followed, the unreachable
# port, and the eleven result-shape paths that run the exchange to completion.

# the step, which is not an incentive next to the 0.2835 C-5 pays. So family

# these that still match. C-5 is otherwise a SHAPE gate -- fourteen records
