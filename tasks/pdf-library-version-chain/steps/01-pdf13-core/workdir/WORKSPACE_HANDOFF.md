Keep this file an accurate description of the repository as you leave it. The next
person to open this workspace reads this first and has no other context.

Record at least:

* **Layout** — which source file holds what, and how they fit together.
* **Build** — the command, and anything non-obvious about it.
* **State** — what works, what is partial, and what is not implemented at all.
  Be specific: "LZWDecode handles /EarlyChange 1 but not 0" is useful; "filters
  mostly work" is not.
* **Known defects** — failures you found and did not fix, with the input that
  reproduces each one.
* **Where you would go next**, and why.
