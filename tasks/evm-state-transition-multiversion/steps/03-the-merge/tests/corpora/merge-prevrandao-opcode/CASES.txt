0001-prevrandao-returns-currentrandom	EIP-4399: 0x44 returns the header's prevRandao field, which --input.env spells currentRandom.
0002-prevrandao-carries-all-32-bytes	EIP-4399 widens 0x44 from a difficulty quantity to the full 32-byte randao; a value with its top byte set is lost by a uint64 path.
0003-prevrandao-zero-randao-still-executes	A zero randao is legal. Slot 0 is then absent either way, so the sentinel in slot 1 separates 'returned zero' from 'never ran'.
0004-prevrandao-with-difficulty-omitted-from-env	EIP-3675 makes the post-merge difficulty 0, so an env that omits currentDifficulty altogether is well-formed and 0x44 still reads the randao.
0005-prevrandao-gas-cost-is-unchanged	EIP-4399: 'the gas cost of the opcode is not changed'. slot0 = the cost of GAS alone (2); slot1 = GAS + PREVRANDAO + POP (6).
0006-prevrandao-inside-a-called-frame	prevRandao is a block-level field, so a CALLed frame reads the same value as the top-level one.
0007-prevrandao-inside-a-staticcall	0x44 reads state it cannot modify, so it is legal inside STATICCALL and returns the randao there too.
