# Third-Party Notices: protobuf-grpc-edition-chain

## 1. Task

Eight-step Protocol Buffers task: carry one protoc-compatible compiler,
runtime, code generator and gRPC stack written in C from proto2 to editions
2024, keeping every earlier era byte-identical to protoc.

## 4. Benchmark modifications

- The 15 well-known-type `.proto` files are copied byte-for-byte from protobuf
  `v32.1`; `tools/embed_wkt.py` embeds their text unchanged in generated C
  string literals in `src/wkt_data.c`.
- `conformance.proto`, `test_messages_proto2.proto` and
  `test_messages_proto3.proto` are copied byte-for-byte from the same tag.
- The five protobuf.dev pages in each step's `SPEC/` are plain-text
  conversions of the rendered documentation pages. The upstream prose is
  unchanged; site navigation and the page footer are retained in the converted
  text.
- `environment/docs/protobuf/` contains five unmodified Markdown files from the
  site repository, including their `+++` front matter.
- `SPEC/protoc-help.txt` reproduces the `--help` output of the official
  `protoc 32.1` release binary.
- The `SPEC/` prose files that are not upstream documentation
  (`conformance-protocol.md`, `extension-ranges.md`, `grpc-http2.md`,
  `python-codegen.md`, `text-format.md`) and all test corpora are authored for
  the benchmark.
- The compiler, runtime, generated-code templates and gRPC implementation under
  `steps/*/solution/` are authored for the benchmark.
