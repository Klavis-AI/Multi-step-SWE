# Milestone 10 of 10 — The number-format engine

You are continuing `seedcalc`, a Go library for OOXML SpreadsheetML documents,
in `/app`. The workspace already holds everything the previous milestones left
behind: their source, the frozen dependency set, the specification corpus under
`/app/specs/`, and the two documents that define the contract this milestone is
specified against. This milestone adds one cumulative capability on top of that.

## 1. Implement this milestone

This milestone applies the number format a cell carries. Until now a cell's custom format code was stored and written but never read back over the value — a style's built-in `numFmtId` rendered, as §4.01.4 says, but a registered `custom_number_format` did not. A format engine arrives here and takes ownership of the read path. It splits a custom format string into up to four sections — positive, negative, zero, text — selects one by the value's sign, and renders the tokens in it. The numeric placeholder is the single character `0`; the date and clock tokens render the workbook's serial numbers, with an elapsed form in square brackets that accumulates past a day; a bracketed hexadecimal LCID selects the language of the month and meridiem names. The engine is deliberately partial, and its partiality is as much part of the requirement as its coverage: a token it does not implement abandons the whole section it appears in and the stored value falls through, so `#,##0` applied to 1234567 is `1234567` and `0.00` applied to 3.14159 is `3.14159`. `General` is recognised and then declined the same way.

The formula library goes from 329 names to 400 — 71 added, **none renamed and none removed**. The plural criteria aggregates `SUMIFS` and `AVERAGEIFS` arrive, taking the aggregated range first where the singular forms take it last, along with the array arithmetic `SUMPRODUCT`, `SUMX2MY2`, `SUMX2PY2`, `SUMXMY2` and `SERIESSUM`. The probability distributions arrive twice over: the pre-2010 spellings (`BETADIST`, `BINOMDIST`, `CHIINV`, `EXPONDIST`, `FDIST`, `GAMMADIST`, `HYPGEOMDIST`, `LOGNORMDIST`, `NEGBINOMDIST`, `TDIST` and their inverses) and the 2010 dotted names beside them, which are **additions and not renames** — every original spelling stays registered, and where the two denote the same function they agree exactly. Several dotted forms take a cumulative flag their originals lack, and `BINOM.DIST.RANGE` has no undotted counterpart at all. The correlation and hypothesis tests `CORREL`, `COVAR`, `MODE`, `CHITEST`, `FTEST`, `TTEST`, `GAUSS` and `PHI` complete the statistical family. And `INDIRECT`, `FORMULATEXT`, `TYPE`, `ERROR.TYPE`, `HOUR`, `SECOND` and `TIMEVALUE` fill the reference, type and clock gaps.

Outside the library there are five changes. Worksheet protection gains the iterated password hash of ECMA-376 §18.3.1.85: `FormatSheetProtection.AlgorithmName` selects one of six digests, and the element carries `algorithmName`, `hashValue`, `saltValue` and `spinCount="100000"` instead of the legacy sixteen-bit `password`, with a fresh salt per call; `UnprotectSheet` grows a variadic password it verifies against either form. The workbook part gains an option interface of exactly the shape the sheet view already uses — `SetWorkbookPrOptions`/`GetWorkbookPrOptions` over `WorkbookPrOption`/`WorkbookPrOptionPtr`, with the new `FilterPrivacy` and the existing `CodeName` serving both roles. The sheet view gains `ShowRuler` and `View`. `SaveAs` begins to police the extension it is handed, accepting exactly five and selecting the workbook content type from it. And four exported identifiers milestone 09 shipped misspelled are corrected, two sentinel messages repaired, one sentinel renamed, and four content-type constants published.

Several of the new behaviours depart from what a reader of the specification would expect, and are required exactly as the Oracle exhibits them. Only the single-character `0` is a numeric placeholder — `00` and `000` are unsupported tokens, and a section containing one yields the **empty string** rather than falling through. Rounding is Go's `%.f`, so it is half-to-even: 2.5 is `2` and 3.5 is `4`. The negative section formats the absolute value and does not re-emit the sign. A single-section format covers positive values only; a negative or zero value under one is not formatted at all. The zero section is parsed but never produces its own text — a zero value always returns the stored value. `mm` is read as minutes only in a clock context, and an elapsed hour does not establish one, so the `mm` after `[h]` is the **month**: `[h]:mm` applied to a February instant ends `:02`. The language identifier is matched on its exact bracketed text, so an IETF tag and a zero-padded LCID are both unrecognised, and an unrecognised one makes the section unsupported rather than falling back to English. `INDIRECT` refuses any sheet-qualified reference, including the containing sheet's own name. `MODE.MULT` is an array function and renders into a cell as the empty string. `SUMPRODUCT` reports mismatched ranges as `#VALUE!` while the sum-of-squares family reports the same mistake as `#N/A`. `SERIESSUM`'s third argument is the exponent *step*, not the exponent. A `ProtectSheet` that fails on the algorithm name or the password length still installs the protection flags, leaving a sheet locked with no password material at all. `View` is not validated, so an unknown mode is stored and written through. And `SaveAs` declares the VBA project extension in every workbook it writes, where `Write` to an `io.Writer` does not.

Four inherited contracts move here, and all four are in scope. A boolean cell **displays** as `TRUE` or `FALSE` where milestone 09 gave `1` and `0` — only the display moves, since the raw value is still the digit and `GetCellType` is still `CellTypeBool`, and `GetRows` carries the word while `GetRows` with `RawCellValue` carries the digit. The fifteen-digit rendering milestone 09 introduced for formula results now counts significant figures everywhere and reaches the **stored** value, so `SetCellValue` of `1/3` stores `0.333333333333333` and `=PI()` is `3.14159265358979`. And `ISERR` and `ISERROR` classify the error they are given instead of propagating it, so `=ISERR(1/0)` is `TRUE` where milestone 07 raised `#DIV/0!`; because the answer is a rendered word, `=ISERR(1/0)+0` now fails in the parser with `strconv.ParseFloat: parsing "TRUE": invalid syntax`. And a failed argument expression is now an error value in **every** argument position — where milestone 09 aborted the call when its last argument failed — so `=ERROR.TYPE(1/0)` is `2` and `=IFERROR(1,2/0)` is `1`. Five exported names are withdrawn at the same time: the four iterator position accessors `Rows.CurrentRow`, `Rows.TotalRows`, `Cols.CurrentCol` and `Cols.TotalCols`, and `XMLHeaderByte`. The `TotalRows` *constant* is a different name and remains. Every other inherited contract from milestones 01–09 remains in scope, including the milestone-09 quirks that did *not* move: the unanchored text criterion, `ADDRESS` discarding its row argument, the non-coercing mixed comparison, `DAY(0)` being `0`, `SetAppProps` replacing rather than merging, `GetCellType` reporting `CellTypeUnset` for a numeric cell, and `File.Close` not being idempotent.
