# implement at this release. The verifier ships it unmodified
# and never consults it when deciding what to score: what is
# scored is the frozen case lists in bogo-groups/, and a case is
# required there or it is not required at all.
#
# An empty reason is upstream's. It is left empty rather than
# filled in here, because a reason invented from the pattern
# name would be a claim about the library that nobody measured.
