NAME:
   evm-geth transition - Executes a full state transition

USAGE:
   evm-geth transition [command options]

OPTIONS:
   
          --trace                             (default: false)                  
                Configures the use of the JSON opcode tracer. This tracer emits traces to files
                as trace-<txIndex>-<txHash>.jsonl
   
          --trace.tracer value                                                  
                Configures the use of a custom tracer, e.g native or js tracers. Examples are
                callTracer and 4byteTracer. These tracers emit results into files as
                trace-<txIndex>-<txHash>.json
   
          --trace.jsonconfig value                                              
                The configurations for the custom tracer specified by --trace.tracer. If
                provided, must be in JSON format
   
          --trace.memory                      (default: false)                  
                Enable full memory dump in traces
   
          --trace.nostack                     (default: false)                  
                Disable stack output in traces
   
          --trace.returndata                  (default: false)                  
                Enable return data output in traces
   
          --trace.callframes                  (default: false)                  
                Enable call frames output in traces
   
          --output.basedir value                                                
                Specifies where output files are placed. Will be created if it does not exist.
   
          --output.alloc value                (default: "alloc.json")           
                Determines where to put the `alloc` of the post-state.
                  `stdout` - into the
                stdout output
                  `stderr` - into the stderr output
                  <file> - into the file <file>
   
          --output.result value               (default: "result.json")          
                Determines where to put the `result` (stateroot, txroot etc) of the
                post-state.
                  `stdout` - into the stdout output
                  `stderr` - into the stderr
                output
                  <file> - into the file <file>
   
          --output.body value                                                   
                If set, the RLP of the transactions (block body) will be written to this file.
   
          --input.alloc value                 (default: "alloc.json")           
                `stdin` or file name of where to find the prestate alloc to use.
   
          --input.env value                   (default: "env.json")             
                `stdin` or file name of where to find the prestate env to use.
   
          --input.txs value                   (default: "txs.json")             
                `stdin` or file name of where to find the transactions to apply. If the file
                extension is '.rlp', then the data is interpreted as an RLP list of signed
                transactions.The '.rlp' format is identical to the output.body format.
   
          --state.fork value                  (default: "GrayGlacier")          
                Name of ruleset to use.

                      EIP158

                      Frontier

$ evm b11r --help
================================================================
NAME:
   evm-geth block-builder - Builds a block

USAGE:
   evm-geth block-builder [command options]

OPTIONS:
   
          --output.basedir value                                                
                Specifies where output files are placed. Will be created if it does not exist.
   
          --output.block value                (default: "block.json")           
                Determines where to put the `block` after building.
                  `stdout` - into the stdout
                output
                  `stderr` - into the stderr output
                  <file> - into the file <file>
   
          --input.header value                (default: "header.json")          
                `stdin` or file name of where to find the block header to use.
   
          --input.ommers value                                                  
                `stdin` or file name of where to find the list of ommer header RLPs to use.
   
          --input.withdrawals value                                             
                `stdin` or file name of where to find the list of withdrawals to use.
   
          --input.txs value                   (default: "txs.rlp")              
                `stdin` or file name of where to find the transactions list in RLP form.
   
          --seal.clique value                                                   
                Seal block with Clique. `stdin` or file name of where to find the Clique sealing
                data.
   
          --help, -h                          (default: false)                  
                show help
